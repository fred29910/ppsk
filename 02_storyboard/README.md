# 分镜

## 内容

- 分镜
- Animatic

## 工具

- 手绘、Krita、Photoshop
- Blender Grease Pencil（推荐 Storyboard 模板）
- AI 草图、简单 3D 方块

## 每格要求

- 镜头编号
- 景别（Wide / Medium / Close-up）
- 机位与运动
- 人物位置与动作
- 对白
- 预计时长
