# 《竹林剑鸣》Animatic 制作计划

> **项目**：仙侠题材 3D 动画 Demo  
> **片长**：30 秒 / 5 镜头 / 24 fps  
> **帧率**：24 fps（共 720 帧）  
> **分辨率**：1920×1080（16:9）  
> **制作阶段**：Animatic（动态分镜）  
> **文档版本**：v1.0

## 一、Animatic 制作流程

### 1.1 制作步骤

```
分镜图 → 镜头粗剪 → 临时音乐 → 节奏调整 → 内部评审 → Story Lock
```

| 步骤 | 内容 | 产出 | 负责 |
|---|---|---|---|
| **Step 1** | 导入分镜图（5 镜头，每镜 2-4 格关键帧） | 分镜序列 | 分镜师 |
| **Step 2** | 按预估时长粗剪，建立时间线骨架 | Animatic v001 | 剪辑师 |
| **Step 3** | 导入临时音乐，对齐音乐结构与镜头切换点 | Animatic v002 | 剪辑师 + 声音设计师 |
| **Step 4** | 根据音乐节奏微调镜头时长与切换点 | Animatic v003 | 剪辑师 |
| **Step 5** | 添加临时音效（剑气、法术、环境音）标记 | Animatic v004 | 声音设计师 |
| **Step 6** | 内部评审，确认节奏与叙事清晰度 | 评审意见 | 导演 + 团队 |
| **Step 7** | 修改定稿，输出 Story Lock 版本 | Animatic Final | 剪辑师 |

### 1.2 工具选择

| 工具 | 用途 | 说明 |
|---|---|---|
| **Blender 5.2 VSE** | Animatic 制作主力 | 与 3D 场景无缝衔接，可直接预览 Layout 动画 |
| **DaVinci Resolve** | 临时音乐剪辑 / 调色参考 | 用于音乐剪辑与画面色调预览 |
| **Krita / Photoshop** | 分镜图绘制 | 分镜阶段已完成 |

**推荐方案**：以 Blender VSE 为核心制作 Animatic，利用其 Sound sockets 功能实现音画同步预览。

### 1.3 时间线结构

```
Blender VSE 时间线结构：
├── Video Track 1: 分镜图 / Layout 预览
├── Video Track 2: 特效占位（剑气、光球、光屑）
├── Video Track 3: 字幕 / 镜头编号
├── Audio Track 1: 临时音乐（立体声）
├── Audio Track 2: 临时音效（剑气、法术）
└── Audio Track 3: 环境音（竹林风声）
```

## 三、剪辑节奏说明

### 3.1 逐镜头剪辑节奏

| 镜头 | 时长 | 剪辑节奏 | 说明 |
|---|---|---|---|
| **sh010** | 6s | **慢** | 远景建立，让观众沉浸于竹林氛围，镜头内部缓慢推进 |
| **sh020** | 5s | **中** | 中景聚焦仙师，节奏适中，突出"睁眼"与"凝聚"两个动作 |
| **sh030** | 7s | **快** | 动作镜头，剪辑点密集，剑气轨迹与竹叶纷飞需要快速切换 |
| **sh040** | 6s | **中** | 跟随镜头，节奏流畅，表现飘逸感 |
| **sh050** | 6s | **慢** | 远景回归，节奏放缓，余韵悠长 |

### 3.2 镜头过渡方式

| 过渡 | 镜头切换 | 时长 | 说明 |
|---|---|---|---|
| **淡入** | 片头 → sh010 | 1s | 从黑场淡入，营造"入画"感 |
| **硬切** | sh010 → sh020 | 0s | 从远景硬切到中景，制造视觉跳跃，暗示"感应" |
| **硬切** | sh020 → sh030 | 0s | 从中景硬切到动作镜头，爆发点 |
| **叠化** | sh030 → sh040 | 0.5s | 从地面动作叠化到空中飞行，空间转换 |
| **叠化** | sh040 → sh050 | 0.5s | 从飞行叠化到远景，仙师消失于云海 |
| **淡出** | sh050 → 片尾 | 1s | 从画面淡出到黑场，余韵 |

**节奏说明**：

## 五、Blender VSE 制作说明

### 5.1 Blender 5.2 Sound Sockets 与 Sync to Audio

Blender 5.2 的 VSE（Video Sequence Editor）引入了 **Sound Sockets** 系统，允许将音频信号直接连接到序列器条带（Strip），实现精确的音频驱动动画。

#### Sound Sockets 核心概念

| 概念 | 说明 |
|---|---|
| **Sound Socket** | 音频条带上的可连接节点，可输出音频信号或包络 |
| **Sync to Audio** | 时间线播放时自动同步音频帧，确保音画同步 |
| **Audio Strip** | VSE 中的音频条带，支持 Sound sockets 输出 |

#### 在 Animatic 中的应用

```
Blender VSE Sound Sockets 工作流：
1. 导入临时音乐到 Audio Strip
2. 在 Audio Strip 上创建 Sound Socket（选择输出类型：Audio / Envelope）
3. 将 Socket 连接到 Video Strip 的某个属性（如透明度、缩放）
4. 启用 Sync to Audio，预览时自动同步
```

## 六、总结

本 Animatic 制作计划以"起承转合"为结构骨架，通过 5 个镜头的节奏变化（慢→中→快→中→慢），配合临时音乐的呼吸感，构建了一个从宁静到爆发、从爆发到空灵的完整叙事弧线。

**关键原则**：
1. **音乐驱动**：无对白，音乐承担全部叙事，镜头切换点与音乐结构点严格对齐
2. **节奏对比**：sh030 的爆发与 sh010/sh050 的宁静形成强烈对比
3. **过渡自然**：硬切用于"感应"与"爆发"，叠化用于空间转换，淡入淡出用于首尾
4. **技术先行**：利用 Blender 5.2 的 Sound Sockets 与 Sync to Audio 功能，确保音画同步预览
