# 归档

## 归档内容

- 发布版资产
- 镜头最终版工程文件
- 最终 EXR
- 合成和调色工程
- 剪辑工程
- 混音工程
- 管线代码
- Project Bible
- 所用 Blender 版本的安装包

## 清理策略

- 中间缓存和旧版本渲染可按策略清理
- 必须保证能用归档内容重新生成最终画面

## 备份原则

遵循 3-2-1 备份原则：

- 3 份副本
- 2 种介质
- 1 份异地

**整个项目期间都要备份，不是等到最后才做。**

## 目录结构

```

├── audio/          # 混音工程
```
