# Layout 模板说明

## 预置内容

- 场景单位：公制，1 unit = 1 m
- 帧率：24 fps
- 分辨率：按 Project Bible 设定
- 色彩管理：AgX / Filmic
- Collection 结构：
  - `CAM_` 摄影机
  - `LGT_` 灯光
  - `GEO_` 场景与代理
  - `RIG_` 角色引用
  - `CTRL_` 控制器

## 使用方式

1. 用此模板新建 `layout.blend`
2. 从 Asset Browser 拖入环境与代理角色
3. 按镜头表设置帧范围
4. 输出摄影机动画和布局

## 检查清单

- [ ] 帧范围符合镜头表
- [ ] 画幅遮罩已启用
- [ ] 代理命名规范
- [ ] 输出路径正确
