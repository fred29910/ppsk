# 音频

## 内容

- 对白（临时/正式）
- 音效
- 音乐
- 混音工程

## 命名规范

```
04_audio/
├── dialogue/
│   ├── scratch/
│   │   └── seq040_sh020_hero_line03_scratch.wav
│   └── final/
│       └── seq040_sh020_hero_line03.wav
├── sfx/
├── music/
│   ├── temp/
│   └── final/
└── mix/
    └── mymovie_mix_v001/
```

## 流程

1. Animatic 阶段录制临时对白（Scratch）
2. 故事锁定后录制正式对白
3. 按镜头切分并命名：`seq040_sh020_hero_line03.wav`
4. 画面锁定后制作音效、环境声
5. 最后混音（对白、音乐、音效分轨）

## 混音规格

- 广播：EBU R128（-23 LUFS）
- 流媒体：-14 到 -16 LUFS
- 声道格式：立体声 / 5.1
