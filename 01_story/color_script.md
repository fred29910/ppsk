## 一、整体色彩设计

### 1.1 色彩主题

**「青竹藏金，剑气破空」** —— 以竹林青绿为基底，法术光球青蓝为转折，剑气金黄为高潮，最终回归青绿余韵。全片色彩走「冷 → 暖 → 冷」的弧线，对应「静 → 动 → 静」的叙事节奏。

### 1.2 核心色板

| 色彩角色 | 色值 (sRGB) | 用途 |
|---|---|---|
| 竹林深绿 | `#1a3a2a` | 环境基调 / 阴影区域 |
| 竹林亮绿 | `#3d7a52` | 竹叶受光面 |
| 云海蓝白 | `#e8f0f8` | 远景背景 |
| 法术青蓝 | `#40c8ff` | 光球 / 法术能量 |
| 法术核心 | `#a0f0ff` | 光球核心高亮 |
| 剑气金黄 | `#ffd700` | 剑气轨迹主体 |
| 剑气核心 | `#fff8e0` | 剑气高亮核心 |
| 光屑暖金 | `#d4af37` | 氛围粒子 |
| 仙师衣袍 | `#f0f0e8` | 角色服装 |

### 1.3 色彩情绪曲线

```
sh010        sh020        sh030        sh040        sh050
宁静   →    警觉   →    爆发   →    升华   →    空灵
青绿         青蓝         金黄         金白         青绿+暖金
低明度       低+点光      高明度       高明度       低中明度
低对比       中对比       高对比       中对比       低对比
```

### 镜头 sh010 —— 竹林打坐（6s）

#### 主色调

| 区域 | 色值 | 说明 |
|---|---|---|
| 竹林基调 | `#1a3a2a` | 深绿，笼罩薄雾 |
| 雾气 | `#8a9a9a` | 蓝灰调，降低饱和度 |
| 远景云海 | `#e8f0f8` | 蓝白，与竹林形成冷暖对比 |
| 仙师衣袍 | `#f0f0e8` | 米白，在暗环境中形成视觉锚点 |

**整体明度**：低明度（Lv 25–35），营造幽深静谧氛围。

#### 光线设计

| 参数 | 值 |
|---|---|
| 主光方向 | 顶部偏后方（模拟晨光穿透竹叶） |
| 色温 | 5500K 冷白偏中性 |
| 对比度 | 低对比（1:2），雾气柔化阴影 |
| 光比 | 主光 : 环境光 = 1 : 1.5 |
| 特殊光效 | 竹叶间隙形成体积光柱（god rays），光柱中可见浮尘 |

#### 色彩情绪关键词

`宁静` `神秘` `幽深` `禅意` `蛰伏`

#### 与前后镜头的色彩过渡

- **→ sh020**：保持竹林绿色基调，逐渐引入青蓝色法术光，明度微升，为「觉醒」做色彩铺垫。

#### 特效色彩说明

| 特效 | 色值 | 透明度 | 运动方式 |
|---|---|---|---|
| 光屑/尘雾 | `#d4af37` 暖金 | 15–25% | 缓慢飘浮，受体积光柱引导 |
| 体积光柱 | `#c8e0e8` 淡青白 | 30–40% | 从竹叶间隙斜射而下 |

#### 主色调

|---|---|---|

| 法术光球中层 | `#40c8ff` | 青蓝色，主体发光 |

#### 光线设计

| 参数 | 值 |
|---|---|
| 主光方向 | 法术光球自发光，从下方照亮仙师面部和手部 |

#### 色彩情绪关键词

`警觉` `凝聚` `专注` `暗涌` `蓄势`

- **→ sh030**：青蓝法术光将转化为金黄剑气，环境光逐渐变暖，色相准备跳变。

#### 特效色彩说明

| 法术光球核心 | `#a0f0ff` | 白青色，最高亮度 |
| 法术光球中层 | `#40c8ff` | 青蓝色，主体发光 |
| 法术光球外层光晕 | `#2080c0` | 深青色，bloom 效果 |
| 光球粒子 | `#c0f0ff` | 青白色，从指尖向外螺旋飘散 |
| 光球闪烁 | — | 频率 2–3Hz，亮度波动 ±15% |

## 五、色彩管理备注

1. **色彩空间**：所有色值为 sRGB 显示参考值，实际制作在 Scene Linear (Rec.709) 空间进行。
2. **视图变换**：AgX 会压缩高光，剑气核心 `#fff8e0` 在 AgX 下呈现柔和白金色，不会过曝。
3. **Look 设置**：None（无额外调色），保持色彩自然还原。
4. **显示输出**：sRGB 显示空间。
5. **软件设置建议**：Blender / Maya 中设置 View Transform = AgX, Look = None, Display = sRGB。
6. **LUT 建议**：如需预览，可加载 AgX Base Contrast 或 Medium High Contrast LUT 作为监看参考。

## 六、色彩设计总结

《竹林剑鸣》的色彩叙事遵循「起承转合」的古典结构：

- **起**（sh010）：青绿基调，宁静神秘
- **承**（sh020）：青蓝注入，警觉蓄势
- **转**（sh030）：金黄爆发，力量释放
- **合**（sh040–sh050）：金白升华，回归青绿余韵

全片以「青」为体、以「金」用，通过色相、明度、饱和度、色温的四维变化，在 30 秒内完成一次完整的色彩情绪弧线，与音乐叙事互为表里。
