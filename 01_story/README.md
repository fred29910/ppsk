# 剧本

## 内容

- 剧本
- 色彩脚本

## 工具

- 文字：任意编辑器
- 色彩脚本：Krita、Photoshop、Blender Grease Pencil

## 流程

1. 故事 → 人物 → 冲突 → 场景 → 镜头 → 时间线
2. 剧本锁定（Script Lock）
3. 输出镜头清单（Shot List）
