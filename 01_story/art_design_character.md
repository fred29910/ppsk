## 一、外貌描述

### 1.1 年龄

**外观年龄：二十五至二十八岁之间。**

面容介于青年与成年之间，既有年轻人的清朗轮廓，又有修行者特有的沉静气质。不显老成，不显稚嫩——恰是"已历风尘，未染世故"的年纪。

### 1.2 面容特征

| 部位 | 描述 |
|---|---|
| **脸型** | 长方脸，下颌线条清晰而不锐利。颧骨微高，面颊略凹，呈现清癯之态。 |
| **眉** | 剑眉，眉峰略扬，眉尾细长。眉色浓黑，与发色一致。眉间距适中，不怒自威。 |
| **眼** | 丹凤眼，眼尾微挑，眼形细长。瞳色深褐近黑，目光沉静时如深潭，警觉时精光内敛。双眼皮褶皱窄而清晰。 |
| **鼻梁** | 高挺笔直，鼻翼收窄，鼻尖微钩。侧面轮廓线条利落。 |
| **唇形** | 薄唇，唇线分明，唇色偏淡。嘴角自然平直，不笑时略显清冷。 |
| **肤色** | 冷白调，似常年吐纳灵气所致，隐隐透出青玉般的质感。面部无明显瑕疵，但非瓷娃娃式的完美——保留一丝真实感。 |
| **耳** | 耳形端正，耳垂薄，耳廓线条简洁。 |

### 1.3 体态

| 项目 | 描述 |
|---|---|
| **身高** | 约 180cm（以场景单位 1 unit = 1m 计） |
| **体型** | 清瘦修长，肩宽适中（约 45cm），腰背挺直。肌肉线条流畅但不夸张，如劲竹般挺拔。 |
| **姿态** | 站立时重心沉稳，双肩自然下沉，双手或负于身后或自然垂放。打坐时脊背笔直如松，不倚不靠。行动时动作干净利落，无多余姿态。 |
| **步态** | 行走时步伐轻盈无声，落地无声如猫。疾行时衣袂翻飞，但上身保持稳定。 |

### 1.4 气质关键词

`清冷` `出尘` `内敛` `飘逸` `果决`

- **清冷**：如霜后竹叶，不带烟火气
- **出尘**：似不食人间烟火，却无疏离之感
- **内敛**：力量含而不发，如剑在鞘中
- **飘逸**：行动时衣袂翻飞，有乘风而去之势
- **果决**：关键时刻毫不犹豫，起身拔剑只在一瞬

## 二、发型设计

### 2.1 发髻样式

**高髻束顶，半束半披。**

- 头顶发髻高约 8cm，呈圆锥形，以一根素玉簪横穿固定。
- 髻根以深色发带缠绕数圈，发带末端自然垂落于髻后，长度约 15cm。
- 后脑及颈后散发自然垂落，长度及肩胛骨中段，不束不编。
- 整体发型介于仙师与侠客之间——既有修道者的超然，又有剑客的利落。

### 2.2 束带/发饰

| 部件 | 描述 |
|---|---|
| **玉簪** | 素白玉簪，长约 18cm，簪头为简单的圆柱形，无雕花。簪身光滑，有温润光泽。 |
| **发带** | 深青色（`#2a4a3a`）丝质发带，宽约 2cm，缠绕髻根后自然垂落。 |
| **鬓发** | 两缕鬓发从耳前自然垂落，长度至下颌，随风微动。 |

### 2.3 发色

**纯黑，带极淡的冷调光泽。**

在光照下呈现墨色般的深邃，边缘有极淡的蓝绿色反光（与竹林环境呼应）。发色不染不饰，保持自然。

### 2.4 刘海/鬓角处理

- **前额**：无刘海，全部梳起，露出完整的额头和发际线。发际线整齐，呈自然的弧形。
- **鬓角**：两缕鬓发从太阳穴前方自然垂落，长度至下颌角，发丝细软，随风微动。
- **颈后**：散发自然垂落，不修剪出层次，保持流畅的线条。

## 三、服装设计

### 3.1 整体款式

**宽袖长袍，交领右衽，衣长及踝。**

整体剪裁宽松飘逸，行动时衣袂翻飞如流云。服装层次分明，共三层：内衣、外袍、披风。

### 3.2 层次结构

| 层次 | 名称 | 描述 |
|---|---|---|
| **内衣** | 中衣 | 月白色（`#f0f0e8`）交领中衣，立领，袖口收窄。长度及踝，作为底色层。 |
| **外袍** | 广袖长袍 | 烟青色（`#5a7a6a`）广袖长袍，交领右衽，袖宽极大（展开约 60cm）。衣长及踝，下摆开衩至膝。 |
| **披风** | 薄纱披风 | 半透明白色薄纱，长度及腰，从肩部自然垂落。行动时飘动最剧烈，增强飘逸感。 |

### 3.3 配色方案

| 色彩角色 | 色值 | 用途 |
|---|---|---|
| **主色** | `#5a7a6a` 烟青 | 外袍主体，占视觉面积最大 |
| **辅色** | `#f0f0e8` 月白 | 内衣、披风底色，提亮整体 |
| **点缀色** | `#c0c8d0` 银灰 | 袖口、领口、下摆的云纹刺绣 |
| **腰带** | `#2a3a3a` 深青黑 | 腰封、丝绦，收束腰线 |
| **装饰** | `#d4af37` 暖金 | 剑穗、玉佩等小面积点缀 |

**配色逻辑**：以烟青为主色，与竹林青绿形成同色系但可区分的层次；月白作为提亮，避免整体暗沉；银灰云纹在光线下若隐若现，增加细节丰富度。

### 3.4 材质描述

| 部件 | 材质 | 视觉特征 |
|---|---|---|
| **中衣** | 细棉麻混纺 | 哑光质感，表面有细微纹理，吸光柔和。 |
| **外袍** | 重磅丝绸 | 表面有柔和的光泽，垂坠感强，褶皱大而流畅。 |
| **披风** | 薄纱 | 半透明，光线可穿透，边缘有极细的卷边。 |
| **腰带** | 织锦 | 表面有暗纹，光泽度中等，质地较硬挺。 |

### 3.5 细节设计

| 部位 | 描述 |
|---|---|
| **袖口** | 广袖袖口宽约 40cm，袖口边缘以银线绣云纹，云纹呈流动状，从袖口向肘部延伸约 15cm。 |
| **领口** | 交领右衽，领缘以银线滚边，宽约 1cm。领口下方可见月白色中衣。 |
| **腰带** | 深青黑织锦腰封，宽约 8cm，于身前偏左位置系结。腰封下垂两条丝绦，长度及膝，末端系有玉佩。 |
| **下摆** | 外袍下摆开衩至膝，便于行动。下摆边缘以银线绣细密云纹，与袖口呼应。 |
| **肩部** | 披风以两枚银质云纹扣固定于肩部，扣子直径约 2cm。 |

## 四、随身物

### 4.1 佩剑

| 项目 | 描述 |
|---|---|
| **名称** | 青锋 |
| **类型** | 直身长剑，单手使用 |

| **剑格** | 简洁的十字形，素铁色，无装饰。 |
| **剑柄** | 缠绕深色丝绳，握感舒适。柄首为圆形，无穗。 |
| **剑鞘** | 深青色木质剑鞘，表面光滑，无雕花。鞘口与鞘尾以素铜包边。 |
| **剑穗** | 深青色丝绦剑穗，长约 20cm，末端系有一枚小型白玉佩。 |
| **佩戴方式** | 平时悬于腰侧，剑柄朝后，便于右手拔剑。 |

| **尘尾** | 白色马尾，长度约 40cm，自然散开，线条流畅。 |
| **佩戴方式** | 悬于腰侧，与佩剑分列左右。平时不用，仅在打坐或施法时取用。 |

### 4.3 其他配饰

| 配饰 | 描述 |

| **云纹扣** | 两枚银质云纹肩扣，固定披风，直径约 2cm。 |
| **靴** | 深色布靴，靴筒及踝，靴底薄而软，便于轻功行动。 |

## 五、表情表

> 无对白，表情承担情绪传达。以下为基础表情设定，供动画师参考。

### 5.1 宁静（sh010 · 打坐）

| 部位 | 状态 |
|---|---|
| **眼** | 闭合，眼睑完全覆盖眼球，睫毛自然下垂。 |
| **眉** | 自然平展，无皱起或下压。 |
| **唇** | 轻闭，嘴角平直，面部肌肉完全放松。 |
| **面部整体** | 无任何紧张感，如沉睡般安详。 |
| **头部** | 微微低垂，下巴内收，面向正前方。 |

### 5.2 警觉（sh020 · 睁眼）

| 部位 | 状态 |
|---|---|
| **眼** | 骤然睁开，瞳孔收缩，目光锐利。眼尾微挑，上眼睑略微上提。 |
| **眉** | 眉峰微聚，眉头轻皱，形成极浅的"川"字纹。 |
| **唇** | 轻闭，嘴角微微下压，面部肌肉开始紧绷。 |
| **面部整体** | 从放松到紧绷的过渡状态，如弓弦将张未张。 |
| **头部** | 从低垂状态抬起，转向画面右上方（远方天际）。 |

### 5.3 专注（sh030 · 挥剑）

| 部位 | 状态 |
|---|---|
| **眼** | 睁大，目光锁定目标，瞳孔聚焦。上眼睑上提，下眼睑微紧。 |
| **眉** | 眉峰下压，眉头紧锁，形成明显的"川"字纹。 |
| **唇** | 紧闭，嘴角下压，咬肌微凸。 |
| **面部整体** | 高度紧张，肌肉收紧，如蓄力待发。 |
| **头部** | 随挥剑动作转动，始终面向目标方向。 |

### 5.4 飘逸（sh040 · 御剑）

| 部位 | 状态 |
|---|---|
| **眼** | 半睁，目光投向前方，眼神悠远。上眼睑放松，不再紧绷。 |
| **眉** | 自然舒展，恢复平展状态，无皱起。 |
| **唇** | 微闭，嘴角自然平直，面部肌肉放松。 |
| **面部整体** | 从紧张回归平静，但眼神中多了一份超脱。 |

## 六、三视图文字描述

> 供原画师参考，描述角色在正面、侧面、背面三个角度的外观特征。

### 6.1 正面视图

**整体印象**：身姿挺拔，如劲竹立于风中。

- **头部**：发髻高束于头顶，玉簪横穿。两缕鬓发从耳前垂落至下颌。面部轮廓清晰，眉目疏朗。
- **颈部**：修长，喉结微凸。
- **肩部**：肩宽适中，线条平直。披风以云纹扣固定于肩部，自然垂落于身后。
- **躯干**：外袍交领右衽，领口呈"y"字形。腰封于身前偏左系结，丝绦自然垂落。
- **手臂**：双臂自然垂于身侧，广袖垂落至膝部，袖口云纹清晰可见。
- **手部**：右手自然垂放，指尖微曲。左手同样自然垂放。
- **下肢**：外袍下摆及踝，开衩处可见内层中衣。双脚分立，与肩同宽。
- **随身物**：佩剑悬于腰侧左侧，剑柄朝后。拂尘悬于腰侧右侧。

### 6.2 侧面视图

**整体印象**：轮廓线条流畅，如刀削般利落。

- **头部**：侧面轮廓清晰，鼻梁高挺，下颌线条分明。发髻呈圆锥形，玉簪从侧面可见。鬓发垂落于耳前。
- **颈部**：微向前倾，与背部形成流畅的曲线。
- **肩部**：肩部线条平直，披风从肩部向后自然垂落。
- **躯干**：外袍侧面线条流畅，腰封收束明显。丝绦从腰侧垂落。
- **手臂**：广袖从侧面看呈宽大的三角形，袖口边缘清晰。
- **手部**：手指自然舒展，指尖微曲。
- **下肢**：外袍下摆侧面开衩，可见内层中衣。双脚一前一后，呈站立姿态。
- **随身物**：佩剑从侧面可见剑身轮廓，剑穗自然垂落。

### 6.3 背面视图

**整体印象**：衣袂飘逸，如即将乘风而去。

- **头部**：发髻从背面可见，发带末端自然垂落于髻后。后脑散发垂落至肩胛骨中段。
- **颈部**：后颈线条清晰，发际线整齐。
- **肩部**：披风从肩部自然垂落，薄纱质感，边缘有极细卷边。
- **躯干**：外袍背面平整，腰封于身后系结，丝绦自然垂落。
- **手臂**：广袖从背面看呈宽大的矩形，袖口云纹环绕。
- **手部**：双手自然垂放，手背朝向后方。
- **下肢**：外袍下摆及踝，背面无开衩，下摆边缘云纹清晰。
- **随身物**：佩剑从背面可见剑鞘全貌，剑穗垂落于腰侧。

## 七、动作特征补充

### 7.1 打坐姿态（sh010）

- 盘坐于空地中央，双腿交叠，右脚在上。
- 双手结印置于膝上，掌心向上，拇指与食指相触。
- 脊背笔直，不倚不靠，双肩自然下沉。
- 衣袍下摆自然铺展于地面，与落叶融为一体。

### 7.2 起身动作（sh030）

- 从盘坐到站立不到一秒，动作极快。
- 先以右脚为支点站起，左脚随即跟上。
- 起身过程中衣袍下摆因动作扬起，形成弧线。
- 起身完成后，立即进入拔剑姿态，无停顿。

### 7.3 御剑姿态（sh040）

- 足踏飞剑，双脚平行站立，与肩同宽。
- 身体微微前倾，重心前移。
- 双手自然垂于身侧，或负于身后。
- 衣袍与发带向后飘扬，形成流线型轮廓。

## 八、与其他元素的视觉关系

| 元素 | 关系 |
|---|---|
| **竹林** | 角色服装的烟青色与竹林青绿形成同色系但可区分的层次。角色在竹林中既融入又突出。 |
| **云海** | 角色服装的月白色与云海蓝白呼应，飞行时与背景形成和谐的色调统一。 |
| **法术光球** | 光球的青蓝色（`#40c8ff`）与角色服装的烟青色形成冷暖对比，光球成为画面视觉焦点。 |
| **剑气** | 剑气的金黄色（`#ffd700`）与角色服装的冷色调形成强烈对比，突出剑气的力量感。 |
| **光屑** | 光屑的暖金色（`#d4af37`）与角色服装的点缀色呼应，增强画面的整体协调性。 |

## 九、制作备注

1. **模型精度**：角色为唯一主角，模型精度需高于其他资产。面部拓扑需支持表情变形，至少包含 4 个基础表情的 blend shape。
2. **服装模拟**：外袍与披风需进行布料模拟，确保行动时衣袂翻飞自然。袖口与下摆的云纹刺绣需考虑模拟后的变形。
3. **发型处理**：散发与鬓发需考虑动力学模拟，确保随风微动自然。发髻与玉簪为刚性体，不需模拟。
4. **随身物绑定**：佩剑与拂尘需绑定至腰部骨骼，确保跟随身体运动自然。
5. **色彩一致性**：角色服装色值需与色彩脚本严格一致，在 Scene Linear (Rec.709) 空间进行材质调整。
