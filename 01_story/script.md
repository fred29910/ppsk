## 一、故事梗概

云海之上，竹林深处。一位仙师于幽篁中打坐修炼，神思沉入太虚。

忽而，远方天际传来一缕异动——那是灾厄将至的征兆。仙师骤然睁眼，眸中精光乍现。他抬起右手，指尖凝聚出一枚法术光球，灵光流转，映照竹影。

仙师起身，拔剑。

一剑挥出，剑气如虹，破空而去。竹叶纷飞，光屑四散，竹林被这道力量劈开一条通路。仙师足踏飞剑，身形拔地而起，衣袂翻飞间，已化作一道流光，没入云海。

竹林重归寂静。唯有剑鸣之声，在竹干之间回荡不绝。

## 三、场景描述

### 竹林

一片幽深竹林，位于山巅平台。竹干笔直高耸，直径约碗口粗细，表皮覆有薄霜般的青白色苔痕。竹叶层叠交错，形成半透明的穹顶，日光从叶隙间滤下，化作细碎光斑洒落地面。

地面铺满枯竹叶与碎石，间生几丛野草。林间有薄雾贴地流动，高度不过膝，随气流缓缓游移。

竹林中央有一小片空地，仙师即于此处打坐。空地边缘可见几块青石，表面被岁月打磨得光滑。

### 云海

竹林之外，视野尽头是一片浩瀚云海。云层翻涌如浪，顶部被天光照亮，呈暖白色；底部沉入阴影，呈青灰色。云海与竹林之间以大气透视过渡，远山轮廓隐约可见，如墨痕晕染。

云海作为远景背景板存在，不做完整资产，以合成雾方式实现。

### 氛围

整体色调偏冷，以青绿、月白、烟灰为主。光线柔和，以顶光与侧逆光为主，营造清晨或黄昏时分的暧昧时刻。空气中悬浮着细微的光屑与尘埃，在光束中闪烁。

### 镜头 sh010

| 项目 | 内容 |
|---|---|
| **镜头编号** | sh010 |
| **时长** | 6 秒（144 帧） |
| **景别** | 远景 |
| **机位** | 高位俯角约 15°，缓慢推进 |
| **叙事功能** | 建立场景与情绪基调——"静" |

#### 画面描述

**构图**：竹林占据画面下三分之二，竹叶穹顶形成天然画框。仙师位于画面中央偏下，身形较小，呈打坐剪影。云海横亘于画面上三分之一处，与竹林以远山轮廓过渡。

**角色状态**：仙师盘坐于空地中央，双手结印置于膝上，脊背笔直，纹丝不动。衣袍下摆自然铺展于地面，与落叶融为一体。

**镜头运动**：摄影机从竹林边缘高位缓慢向仙师方向推进，推进速度极慢，6 秒内位移约 3 米。同时焦点从竹叶前景缓缓转移至仙师身上，形成浅景深效果。

**光影**：日光从画面右上方斜射入林，在竹干上形成明暗交替的条纹。仙师身体右侧被照亮，左侧隐入阴影。光斑透过竹叶在地面游移。

#### 特效描述

| 特效 | 实现 | 说明 |
|---|---|---|
| **光屑/尘雾** | GN Simulation Zone + Point Instance | 空气中悬浮的微小光点，密度稀疏，缓慢上升或漂移。在光束照射区域可见度较高。 |
| **贴地薄雾** | 渲染器体积（近景） | 高度约 30cm，沿地面缓慢流动，绕过竹干与石块。 |

#### 情绪与节奏

**情绪**：宁静、神秘、悠远。

**节奏**：极缓。画面中几乎无可见运动，唯有光斑游移与薄雾流动暗示时间流逝。

#### 音乐/音效提示

| 时间点 | 内容 |
|---|---|
| 0:00 | 音乐起。古琴单音，一个低沉的散音，余韵悠长。 |
| 0:01–0:03 | 加入竹叶沙沙声（环境音），极轻，似有若无。 |
| 0:03–0:06 | 古琴第二个音加入，与第一个音形成五度共鸣。远处隐约传来一声鸟鸣，随即归于寂静。 |

### 镜头 sh020

| 项目 | 内容 |
|---|---|
| **镜头编号** | sh020 |
| **时长** | 5 秒（120 帧） |
| **景别** | 中景 |
| **机位** | 平视，略低于仙师视线，固定 |
| **叙事功能** | 转折——"觉" |

#### 画面描述

**构图**：仙师位于画面中央偏左，上半身入画。背景为虚化的竹干与光斑，形成纵向线条的散景。画面右侧留出负空间，暗示远方。

**角色动作**：

- **0:00–0:01**：仙师双眼骤然睁开。瞳孔收缩，目光投向画面右上方（远方天际）。
- **0:01–0:02**：右手从膝上抬起，掌心向上，缓缓移至胸前。手指自然舒展，指尖朝上。
- **0:02–0:05**：指尖开始凝聚光球。最初为一点微光，逐渐增大至乒乓球大小。光球呈暖白色，内部有流光旋转，表面有电弧般的细丝跳动。

**镜头运动**：固定机位，无运动。焦点锁定仙师面部与右手之间，景深较浅。

**光影**：光球成为画面第二光源，在仙师面部右侧投下暖色补光，与左侧冷色环境光形成对比。光球亮度随凝聚过程递增。

#### 特效描述

| 特效 | 实现 | 说明 |
|---|---|---|
| **法术光球** | 球体 + Emission + 合成辉光 | 核心为自发光球体，外层包裹电弧纹理。辉光在合成层叠加，注意 AgX 下不发白（per-shot 色彩策略）。 |
| **指尖光丝** | 曲线 + 自发光 | 从指尖延伸出的细小光丝，随光球增大而增多，呈放射状。 |

#### 情绪与节奏

**情绪**：警觉、凝聚、蓄势。

**节奏**：由静转动。睁眼为瞬间动作，抬手为缓动，光球凝聚为持续加速。整体节奏前慢后快，在镜头末尾达到凝聚的临界点。

#### 音乐/音效提示

| 时间点 | 内容 |
|---|---|
| 0:00 | 古琴音戛然而止。寂静半拍。 |
| 0:00.5 | 一声极轻的剑鸣（金属泛音），暗示感应。 |
| 0:01–0:03 | 加入低频持续音（drone），音量渐强，制造紧张感。 |
| 0:03–0:05 | 法术光球凝聚时，加入灵光嗡鸣声，频率随光球增大而升高。 |

### 镜头 sh030

| 项目 | 内容 |
|---|---|
| **镜头编号** | sh030 |
| **时长** | 7 秒（168 帧） |
| **景别** | 全景 → 中景（随动作变化） |
| **机位** | 低角度仰拍，随挥剑动作弧形移动 |
| **叙事功能** | 爆发——"动" |

#### 画面描述

**构图**：初始为低角度全景，仙师位于画面中央，竹林向画面上方汇聚，形成强烈的纵深感。挥剑过程中，摄影机沿弧形轨迹移动，视角从仰拍逐渐过渡到平视。

**角色动作**：

- **0:00–0:01.5**：仙师起身。动作极快，从盘坐到站立不到一秒。衣袍下摆因起身动作扬起，形成弧线。
- **0:01.5–0:02.5**：右手拔剑。剑出鞘的瞬间，剑身反射一道寒光。左手同时松开光球，光球悬浮于身侧。
- **0:02.5–0:04.5**：挥剑。仙师以右脚为轴，身体旋转 180°，剑从右下向左上方划出一道弧线。剑尖轨迹经过之处，空气被撕裂，形成可见的剑气。
- **0:04.5–0:07**：剑气脱剑而出，呈月牙形向前飞射。剑气经过的路径上，竹叶被卷起、撕裂，竹干表面出现细微裂痕。仙师保持挥剑后的收势，衣袍与发带仍在飘动。

**镜头运动**：摄影机以仙师为圆心，沿逆时针方向弧形移动约 60°，同时从低角度抬升至平视。移动速度与挥剑节奏同步。

**光影**：挥剑瞬间，剑气成为画面最强光源，在竹林中投下动态光影。竹叶上的光斑随剑气经过而剧烈闪烁。

#### 特效描述

| 特效 | 实现 | 说明 |
|---|---|---|
| **剑气轨迹** | GN Curve + 自发光 + 合成辉光 | 月牙形剑气，核心为白热色，边缘渐变为青蓝色。轨迹在挥剑后残留约 1 秒，随后消散。 |
| **光屑** | GN Simulation Zone + Point Instance | 剑气经过处，竹叶碎片与光屑混合飞散。光屑密度高于 sh010，运动方向与剑气方向一致。 |
| **竹叶飞散** | Cloth / 粒子 | 被剑气卷起的竹叶，沿抛物线轨迹飘落。 |

#### 情绪与节奏

**情绪**：力量、爆发、畅快。

**节奏**：全片最快。起身、拔剑、挥剑三个动作紧密衔接，中间无停顿。剑气脱剑后节奏稍缓，但余势未消。

#### 音乐/音效提示

| 时间点 | 内容 |
|---|---|
| 0:00 | 古琴重音（扫弦），如惊雷炸响。 |
| 0:01.5 | 剑出鞘的金属摩擦声，短促锐利。 |
| 0:02.5 | 挥剑破空声，低沉的呼啸。 |
| 0:03 | 剑气释放的瞬间，一声清越剑鸣（高频金属泛音），贯穿全镜。 |
| 0:04.5–0:07 | 竹叶碎裂与飞散的细碎声，叠加剑鸣余韵。 |

### 镜头 sh040

| 项目 | 内容 |
|---|---|
| **镜头编号** | sh040 |
| **时长** | 6 秒（144 帧） |
| **景别** | 中景 → 远景（随飞行距离变化） |
| **机位** | 侧面跟随，与仙师保持等速移动 |
| **叙事功能** | 升华——"飞" |

#### 画面描述

**构图**：初始为侧面中景，仙师位于画面中央偏左，飞剑平行于地面。背景为竹林侧面与上方天空。随着飞行，竹林逐渐下沉至画面下方，云海逐渐占据画面上方。

**角色动作**：

- **0:00–0:01**：仙师足踏飞剑，身体微微前倾，衣袍与发带向后飘扬。双手自然垂于身侧，目光投向前方。
- **0:01–0:03**：飞剑加速，仙师身形逐渐上升。衣袍下摆剧烈翻飞，形成流线型轮廓。
- **0:03–0:06**：仙师与飞剑化为一道流光，向云海方向飞去。身形逐渐缩小，最终成为画面中的一个亮点。

**镜头运动**：摄影机与仙师保持等速横向移动，同时缓慢上升。移动过程中，焦点始终锁定仙师，背景因运动而产生方向性模糊。

**光影**：仙师从竹林阴影中飞出，进入天光照射区域。身体轮廓被逆光勾勒出一道金边。飞剑尾迹在身后留下一道渐隐的光带。

#### 特效描述

| 特效 | 实现 | 说明 |
|---|---|---|
| **剑气轨迹（尾迹）** | 曲线 + 自发光 + 合成辉光 | 飞剑尾迹呈细长流线型，颜色从白热渐变为淡青。尾迹长度约 10 米，随飞行逐渐消散。 |
| **光屑** | GN Simulation Zone + Point Instance | 尾迹周围散布细小光点，密度随距离增加而递减。 |

#### 情绪与节奏

**情绪**：飘逸、升华、超脱。

**节奏**：由动转静。起飞时速度感强烈，随后逐渐舒展、放缓。镜头末尾，画面趋于平静，唯余尾迹缓缓消散。

#### 音乐/音效提示

| 时间点 | 内容 |
|---|---|
| 0:00 | 古琴音转为泛音，空灵飘逸。 |
| 0:00–0:02 | 风声渐强，衣袍猎猎作响。 |
| 0:02–0:04 | 飞剑破空声，尖锐但渐远。 |
| 0:04–0:06 | 音乐渐弱，风声渐远，最终归于一声悠远的古琴泛音。 |

**环境变化**：竹林在 sh030 中被剑气劈开的路径仍然可见——一条隐约的通道，竹叶稀疏，竹干上有细微裂痕。通道中的光屑仍在缓缓飘落。

| 特效 | 实现 | 说明 |

| **云海微光** | 合成雾 + 局部辉光 | 仙师消失处，云层内部有微弱的光晕扩散，直径约 2 米，持续约 2 秒后消散。 |

#### 情绪与节奏

**情绪**：空灵、余韵、怅然。

**节奏**：极缓，与 sh010 呼应。画面中无显著运动，唯有光屑飘落与云层微光暗示方才发生的一切并非幻觉。

#### 音乐/音效提示

| 0:00–0:02 | 古琴泛音延续自 sh040，音量极轻。 |

| 0:04–0:06 | 一声极远的剑鸣回荡，似从云海深处传来，随后归于寂静。 |

## 六、技术备注

| 项目 | 说明 |
