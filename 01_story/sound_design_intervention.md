# 《竹林剑鸣》声音设计介入说明

> **项目**：仙侠题材 3D 动画 Demo  
> **片长**：30 秒 / 5 镜头 / 24 fps  
> **音频规格**：48 kHz / 24 bit / 立体声 / -14 LUFS / 真峰值 ≤ -1.0 dBTP  
> **文档定位**：声音设计团队在项目各阶段的介入点、交付物与协作接口

---

## 一、音乐结构点

### 1.1 起（sh010 · 0:00–0:06）

| 项目 | 内容 |
|---|---|
| **进入时间码** | 0:00.0（帧 0） |
| **乐器** | 古琴（泛音）、箫（长音）、环境合成器铺底 |
| **情绪** | 宁静 → 神秘 |
| **音乐动作** | 古琴泛音第一声如露水滴落，箫声从远处隐约浮现，合成器铺底营造空间感。节奏自由散板，约 60 BPM 呼吸感。 |
| **介入要点** | 音乐在片头即进入，与画面"竹林全景"同步建立氛围。古琴泛音作为全片音乐动机的种子，需在 Animatic 阶段确定其音色与音高。 |

### 1.2 转（sh020–sh030 · 0:06–0:18）

| 项目 | sh020（0:06–0:11） | sh030（0:11–0:18） |
|---|---|---|
| **时间码** | 0:06.0（帧 144） | 0:11.0（帧 264） |
| **乐器变化** | 古琴泛音 → 按音滑奏；低音弦乐拨奏进入；磬声标记节点 | 大鼓、锣、琵琶（扫弦/轮指）、弦乐组、合唱（哼鸣）全奏 |
| **情绪转折** | 神秘 → 紧张 → 蓄势 | 紧张 → 磅礴 → 爆发 |
| **音乐动作** | 古琴音色由空转实，低音脉冲提供心跳感，0:10 处所有乐器短暂静默为爆发留白 | 大鼓重击 + 锣声对应"起身挥剑"，琵琶轮指如剑光闪烁，0:15 全奏爆发至顶点 |
| **介入要点** | 0:06 古琴音色转变标志"睁眼"，需与动画师对齐动作帧；0:10 静默是"屏息"瞬间，需与剪辑确认留白时长 | 0:11 大鼓重击是音乐与画面的第一次"硬切"对齐点；0:15 全奏最强音需与剑气顶点特效同步 |

### 1.3 收（sh040–sh050 · 0:18–0:30）

| 项目 | sh040（0:18–0:24） | sh050（0:24–0:30） |
|---|---|---|
| **时间码** | 0:18.0（帧 432） | 0:24.0（帧 576） |
| **乐器** | 箫（主旋律）、古琴（分解和弦）、弦乐组（长音）、风铃 | 古琴（泛音）、箫（尾音）、环境合成器 |
| **情绪** | 飘逸、升华、超脱 | 空灵、余韵、宁静 |
| **音乐动作** | 箫声接管主旋律，音乐由密转疏，0:23 达到旋律高点后开始消散 | 音乐进一步稀薄，0:27 箫声尾音消散，0:29 完全淡出，只留环境音与剑鸣余韵 |
| **介入要点** | 0:18 箫声进入是音乐"换主角"的时刻，需与画面"御剑而起"同步；旋律高点需与仙师飞至最高点对齐 | 0:29 音乐淡出后，环境音与剑鸣余韵接管，需确认余韵的混响尾长与画面"重归宁静"的匹配 |

## 二、关键音效点

> 以下 5 个音效点对应全片最关键的剧情节点，需精确到帧制作与对齐。

### 音效点 1：剑鸣·感应

| 项目 | 内容 |
|---|---|
| **音效名称** | 剑鸣·感应（Sword Sense） |
| **时间码** | 0:06.25（帧 150） |
| **剧情节点** | sh020 开始，仙师骤然睁眼——感应到远方危机 |
| **音效描述** | 一声极轻的金属泛音，如剑身自行振动。高频（3–5 kHz）为主，带有仙侠风格的"灵气"尾韵。音量极低（-30 dBFS），似有若无，暗示仙师与剑之间的精神共鸣。持续约 0.5 秒，迅速衰减。 |

### 音效点 2：法术启动·能量聚集

| 项目 | 内容 |
|---|---|
| **音效名称** | 法术启动（Magic Charge） |
| **时间码** | 0:07.0（帧 168） |
| **剧情节点** | sh020 中段，仙师指尖开始凝聚法术光球 |
| **音效描述** | 低频"嗡"声由低到高渐强，基频 80–120 Hz，泛音延伸至 8 kHz。使用环形调制制造"灵气"感，叠加轻微颤音。音量从 -24 dBFS 渐强至 -12 dBFS，与光球增大同步。持续约 3 秒，在 0:10 达到顶点后突然静默。 |

### 音效点 3：剑鸣·出鞘

| 项目 | 内容 |
|---|---|
| **音效名称** | 剑鸣·出鞘（Sword Draw） |
| **时间码** | 0:11.0（帧 264） |
| **剧情节点** | sh030 开始，仙师起身拔剑——剑出鞘的瞬间 |
| **音效描述** | 金属剑身与剑鞘摩擦的"铮"声，短促锐利（持续约 0.3 秒）。中高频（1–4 kHz）突出，带有金属质感。音量较高（-6 dBFS），是全片第一个"硬"音效。叠加短混响（RT60 ≈ 0.8s），营造竹林空间感。 |

### 音效点 4：剑气破空·释放

| 项目 | 内容 |
|---|---|
| **音效名称** | 剑气破空（Sword Qi Release） |
| **时间码** | 0:11.5（帧 276） |
| **剧情节点** | sh030 中段，仙师挥剑，剑气脱剑而出 |
| **音效描述** | 剑气划过空气的"嗖"声，带有金属质感与能量闪烁。使用带通滤波噪声 + 音高下滑（Pitch Drop），中频（500 Hz – 2 kHz）突出。声像从左至右快速移动（根据画面方向）。音量峰值 -3 dBFS，持续约 1 秒，叠加长混响（RT60 ≈ 2s）与延迟（1/4 音符）。 |

### 音效点 5：剑鸣·余韵

| 项目 | 内容 |
|---|---|
| **音效名称** | 剑鸣·余韵（Sword Echo） |
| **时间码** | 0:24.0（帧 576） |
| **剧情节点** | sh050 开始，仙师已消失于云海，竹林重归宁静 |
| **音效描述** | 剑鸣在混响中慢慢消散的余韵，似从云海深处传来。高频金属泛音（2–5 kHz）为主，低频做高通滤波。音量从 -18 dBFS 逐渐衰减至 -40 dBFS，持续约 4 秒。使用长延迟（1/4 音符 + 1/2 音符）向左右声道扩散，营造"回荡不绝"的空间感。 |

## 三、镜头入点/出点与音乐的呼吸对齐

### 3.1 镜头边界与音乐呼吸

| 镜头 | 入点（时间码） | 出点（时间码） | 音乐呼吸 | 对齐关系 |
|---|---|---|---|---|
| **sh010** | 0:00.0（帧 0） | 0:06.0（帧 144） | 起音 → 舒展 | 音乐起音与镜头入点同步；镜头出点落在箫声长音的"呼吸间隙" |
| **sh020** | 0:06.0（帧 144） | 0:11.0（帧 264） | 凝聚 → 屏息 | 镜头入点与古琴音色转变同步；出点落在 0:10 静默后的"屏息"瞬间 |
| **sh030** | 0:11.0（帧 264） | 0:18.0（帧 432） | 爆发 → 释放 | 镜头入点与大鼓重击同步；出点落在全奏开始收束的"换气"处 |
| **sh040** | 0:18.0（帧 432） | 0:24.0（帧 576） | 上升 → 消散 | 镜头入点与箫声进入同步；出点落在旋律高点后的"消散"起点 |
| **sh050** | 0:24.0（帧 576） | 0:30.0（帧 719） | 余韵 → 宁静 | 镜头入点与音乐稀薄同步；出点落在音乐完全淡出后的"空白"处 |

### 3.2 剪辑节奏建议

| 剪辑点 | 位置 | 建议 |
|---|---|---|
| sh010 → sh020 | 0:06.0 | **硬切**。古琴音色转变与画面切换同步，制造"睁眼"的冲击感。不建议溶接，保持节奏的干净利落。 |
| sh020 → sh030 | 0:11.0 | **硬切**。大鼓重击与画面切换同步，是全片节奏的"爆点"。静默（0:10）后立即切入，制造"蓄势-爆发"的对比。 |
| sh030 → sh040 | 0:18.0 | **软切（1–2 帧溶接）**。音乐由密转疏的"换气"处切换，保持动作的连贯性。箫声进入与御剑起飞同步。 |
| sh040 → sh050 | 0:24.0 | **软切（2–4 帧溶接）**。音乐渐弱处切换，保持飘逸感。可考虑在 sh040 末尾加入 1 帧黑场过渡，增强"消失"感。 |

### 3.3 呼吸对齐原则

1. **镜头入点对齐音乐"起音"或"重音"**：每个镜头的开始尽量落在音乐的起音、重音或音色转变点上，增强音画同步感。
2. **镜头出点对齐音乐"呼吸间隙"**：镜头的结束尽量落在乐句的间隙、长音的衰减处或静默处，给观众"换气"的空间。
3. **动作镜头（sh030）对齐音乐"强拍"**：动作镜头的入点必须与音乐的强拍（大鼓重击）严格对齐，误差不超过 1 帧。
4. **过渡镜头（sh040–sh050）对齐音乐"消散"**：过渡镜头的剪辑点落在音乐渐弱或消散处，保持情绪的连贯与飘逸。

## 四、Animatic 阶段的介入项

### 4.1 临时音乐的选择/创作方向

| 项目 | 内容 |
|---|---|
| **选择策略** | 选用 2–3 首风格相近的临时音乐（Temp Music），覆盖"宁静-爆发-空灵"的情绪弧线。优先选择带有古琴、箫、大鼓等东方乐器元素的曲目。 |
| **创作方向** | 若临时音乐无法完全匹配，可创作一段 30 秒的简易临时音乐：古琴泛音 + 箫长音 + 合成器铺底（sh010-sh020）→ 大鼓 + 琵琶轮指（sh030）→ 箫主旋律 + 古琴分解和弦（sh040-sh050）。 |
| **参考曲目** | 仙侠/武侠类动画配乐（如《大鱼海棠》《雾山五行》等作品的配乐风格），重点参考其乐器搭配与情绪节奏。 |
| **交付格式** | 临时音乐以 WAV / 48 kHz / 24 bit 交付，导入 Blender VSE 后与画面对齐。 |

### 4.2 音效点标记方法

| 步骤 | 内容 |
|---|---|
| **1. 标记位置** | 在 Animatic 时间轴上，用 Marker（标记）标注 5 个关键音效点的位置（见第二节）。Marker 命名规则：`SFX_序号_名称`，如 `SFX_01_剑鸣感应`。 |
| **2. 临时音效** | 在标记位置放置临时音效（可用库音效或简易合成音效），用于验证音效点与画面的对齐关系。临时音效以"能听出节奏和位置"为标准，不追求最终音质。 |
| **3. 对齐验证** | 播放 Animatic，检查每个音效点是否与画面动作严格对齐。误差超过 1 帧的，调整音效点位置或画面动作。 |
| **4. 文档记录** | 将确认后的音效点位置记录在 `sound_design.md` 的"逐镜头音效点"表格中，作为正式制作的依据。 |

### 4.3 Blender VSE 中的音频同步设置

| 设置项 | 推荐值 | 说明 |
|---|---|---|
| **帧率** | 24 fps | 与项目统一 |
| **音频采样率** | 48 kHz | 与交付规格一致 |
| **音频缓冲区** | 2048 samples | 平衡延迟与稳定性 |
| **同步模式** | `AV-sync`（音视频同步） | 确保音画同步，避免漂移 |
| **音频通道** | 立体声（2ch） | 与交付规格一致 |
| **音频格式** | WAV / 24 bit | 无损格式，避免压缩伪影 |
| **时间轴显示** | 开启"显示音频波形" | 便于精确对齐音效点 |
| **Marker 显示** | 开启"显示 Marker" | 便于查看音效点标记位置 |

#### VSE 轨道布局建议

```
轨道 5: [SFX]      ← 音效轨（精确到帧）
轨道 4: [Foley]    ← 拟音轨（跟随画面）
轨道 3: [Ambience] ← 环境音轨（持续铺底）
轨道 2: [Music]    ← 音乐轨（叙事主体）
轨道 1: [Video]    ← 视频轨（画面）
```

#### 音频同步检查清单

- [ ] 临时音乐已导入并与画面对齐
- [ ] 5 个关键音效点已用 Marker 标记
- [ ] 临时音效已放置在标记位置
- [ ] 音画同步误差不超过 1 帧
- [ ] 音频采样率设置为 48 kHz
- [ ] 同步模式设置为 `AV-sync`
- [ ] 音频波形已显示，便于检查

## 五、交付物与时间节点

| 阶段 | 交付物 | 负责方 | 备注 |
|---|---|---|---|
| **Animatic** | 临时音乐 + 临时音效 + 音效点标记 | 声音设计 | 本节 4.1–4.3 内容 |
| **Layout/Blocking** | 音乐结构点确认 + 关键音效点确认 | 声音设计 + 导演 | 第一、二节内容 |

| **Final Mix** | 分轨混音 + 终混 | 声音设计 | 按 sound_design.md 混音说明执行 |
