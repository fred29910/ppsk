# 《竹林剑鸣》场景设定与 FX 风格参考

> 仙侠 3D 动画 Demo · 30 秒 · 5 镜头 · 24 fps
> 本文档定义竹林场景的视觉基调与三种 P0 特效的风格标准，供建模、特效、灯光、合成各环节统一参考。

---

## 一、场景设定：竹林

### 1.1 整体环境

竹林生长于山巅平台，是一片幽深而不过分茂密的毛竹林。竹干笔直高耸，高度约 12–15 米，直径碗口粗细（15–20 cm），间距 1.5–2.5 米，形成可穿行其间的纵深感。竹林中央有一片直径约 6 米的圆形空地，仙师即于此处打坐。

竹林密度由外向内递减：外围竹干密集，形成天然屏障；向内逐渐疏朗，至空地边缘仅余数株老竹。竹叶层叠交错于 8–12 米高度，构成半透明的穹顶，日光从叶隙间滤下，化作细碎光斑洒落地面。

**氛围关键词**：幽深、静谧、禅意、蛰伏、空灵

### 1.2 光影特点

**时间设定**：清晨与黄昏之间的暧昧时刻，太阳低角度悬于天际。

| 参数 | 值 |
|---|---|
| 主光方向 | 顶部偏后方，与画面呈 30°–45° 夹角 |
| 色温 | 5500K 冷白偏中性（sh010/sh020）→ 4800K 中性偏暖（sh050） |
| 对比度 | 低对比（1:2），雾气柔化阴影 |
| 光比 | 主光 : 环境光 = 1 : 1.5 |

**体积光（God Rays）**：晨光穿透竹叶间隙，形成 5–8 道可见的斜射光柱，光柱角度随竹叶摆动而微微晃动。光柱中悬浮的浮尘与光屑清晰可见，成为画面中「时间流逝」的视觉提示。

**薄雾**：贴地流动，高度约 30 cm，沿地面缓缓游移，绕过竹干与石块。雾气密度极低，仅在近景处可见，不遮挡中远景。

**竹叶透光**：竹叶呈半透明质感，逆光时叶脉清晰可见，边缘形成明亮的轮廓光。阳光直射处竹叶呈亮绿色（`#3d7a52`），背光处融入深绿阴影（`#1a3a2a`）。

### 1.3 地面描述

| 元素 | 描述 |
|---|---|
| 枯竹叶 | 铺满地面，厚度约 2–3 cm，呈黄褐色与灰绿色混合，边缘卷曲 |
| 苔藓 | 竹干基部及石块表面覆有薄霜般的青白色苔痕，暗示潮湿阴凉的环境 |
| 石板 | 空地边缘散落数块青石，表面被岁月打磨得光滑，部分陷入泥土 |
| 野草 | 石缝间生出几丛野草，叶片细长，随风微动 |
| 碎石 | 小径上有零星碎石，直径 3–8 cm，表面干燥 |

**地面色彩**：以灰褐（`#4a4038`）为基底，叠加枯叶黄褐（`#8a7a5a`）与苔藓青绿（`#5a7a6a`），整体饱和度低，与竹干形成冷暖对比。

### 1.4 背景板：云海与远山

竹林之外，视野尽头是一片浩瀚云海，作为远景背景板存在。

| 元素 | 描述 |
|---|---|
| 云层顶部 | 被天光照亮，呈暖白色（`#e8f0f8`），边缘柔和 |
| 云层底部 | 沉入阴影，呈青灰色（`#8a9a9a`），与竹林深绿形成层次 |
| 远山轮廓 | 云海与竹林之间以大气透视过渡，远山如墨痕晕染，仅见剪影 |
| 天空 | 画面上部为淡蓝白色，向地平线方向渐变为暖白 |

**实现方式**：云海不做完整 3D 资产，以合成雾（Depth + Mist + Fog Glow）方式实现，确保与竹林的纵深距离感。

### 1.5 色彩基调

全片色彩遵循「青绿 + 金」的双色体系：

| 色彩角色 | 色值 | 用途 |
|---|---|---|
| 竹林深绿 | `#1a3a2a` | 环境基调 / 阴影区域 |
| 竹林亮绿 | `#3d7a52` | 竹叶受光面 |
| 云海蓝白 | `#e8f0f8` | 远景背景 |
| 仙师衣袍 | `#f0f0e8` | 角色服装，暗环境中的视觉锚点 |
| 暖金点缀 | `#d4af37` | 光屑 / 边缘光 / 余韵 |

**色彩情绪弧线**：

```
sh010        sh020        sh030        sh040        sh050
宁静   →    警觉   →    爆发   →    升华   →    空灵
青绿         青蓝         金黄         金白         青绿+暖金
低明度       低+点光      高明度       高明度       低中明度
```

### 1.6 氛围关键词汇总

`幽深` `静谧` `禅意` `晨光` `薄雾` `浮尘` `竹影` `空灵` `余韵`

## 二、FX 风格参考

### 2.1 剑气轨迹（sh030 / sh040）

剑气是全片视觉冲击力最强的特效，代表仙师的力量与决心。它不是简单的「光带」，而是具有实体感与速度感的能量轨迹。

#### 颜色

| 层级 | 色值 | 说明 |
|---|---|---|
| 核心 | `#fff8e0` | 白金色，最高亮度，能量最密集处 |
| 中层 | `#ffd700` | 金黄色，主体轨迹，占视觉面积最大 |
| 边缘 | `#ff8c00` | 橙金色，衰减区域，向外扩散后迅速消散 |
| 尾迹（sh040） | `#a0d0ff` → `#e0f0ff` | 青金到白蓝渐变，随距离增加而冷却 |

**渐变方向**：沿轨迹宽度方向，由核心向边缘渐变；沿轨迹长度方向，由前端向后端渐变。

#### 形态

| 参数 | sh030（挥剑） | sh040（飞行尾迹） |
|---|---|---|
| 形状 | 月牙形弧线，曲率半径约 1.2 m | 细长流线型，宽度逐渐扩散 |
| 核心宽度 | 2–3 px | 1–2 px |
| 光晕宽度 | 8–12 px | 4–6 px |
| 拖尾长度 | 30–50 px | 15–20 帧（约 0.8 秒） |
| 整体长度 | 约 2–3 m（画面内） | 约 10–15 m（随飞行延伸） |

**形态特征**：
- 轨迹边缘呈不规则的「撕裂状」，非平滑曲线，暗示空气被力量强行破开
- 核心区域有细微的「电弧」状分支，长度 2–5 cm，随机闪烁
- 轨迹前端（运动方向）较尖锐，后端较宽且渐隐

#### 运动特征

| 参数 | 值 |
|---|---|
| 速度 | 挥剑时约 8–12 m/s（画面内），飞行时约 15–20 m/s |
| 轨迹 | 挥剑时为弧线，飞行时为直线略带弧度 |
| 拖尾 | 挥剑后残留约 1 秒，随后从后端向前端消散 |
| 闪烁 | 核心区域有 2–3 Hz 的亮度波动，幅度 ±10% |

**运动质感**：剑气不是「匀速」运动，而是带有「爆发—衰减」的节奏。挥剑瞬间速度最快，随后逐渐减缓；飞行时速度恒定，但尾迹长度随距离增加而缩短。

#### 发光强度

| 参数 | 值 |
|---|---|
| 核心亮度 | 800–1200 nits（峰值） |
| 中层亮度 | 400–600 nits |
| 边缘亮度 | 100–200 nits |
| Bloom 范围 | 核心向外扩散 20–30 px |
| Bloom 强度 | 0.6–0.8（合成层） |

**AgX 注意事项**：剑气核心 `#fff8e0` 在 AgX 下会压缩为柔和白金色，不会过曝。如需更强烈的视觉冲击，可在合成层叠加 per-shot 色彩调整。

#### 与角色的接触关系

- **挥剑时（sh030）**：剑气从剑尖延伸而出，初始段与剑身重叠约 10 cm，随后脱剑飞出。剑身被剑气照亮，反射金黄色光芒。
- **飞行时（sh040）**：飞剑尾迹从剑身尾部延伸，宽度约剑身的 2–3 倍。仙师身体位于尾迹前端，被尾迹光芒从后方照亮，形成逆光剪影。

### 2.2 法术光球（sh020）

法术光球是仙师感应危机的视觉化表现，代表灵气的凝聚与觉醒。它不是静止的「灯泡」，而是有生命感的能量体。

#### 颜色

| 层级 | 色值 | 说明 |
|---|---|---|
| 核心 | `#a0f0ff` | 白青色，最高亮度，能量核心 |
| 中层 | `#40c8ff` | 青蓝色，主体发光，占视觉面积最大 |
| 外层光晕 | `#2080c0` | 深青色，bloom 效果，向外扩散 |
| 粒子 | `#c0f0ff` | 青白色，从指尖向外螺旋飘散 |

**渐变方向**：由核心向外，亮度与饱和度同时递减。核心区域几乎为白色，边缘融入环境。

#### 大小

| 阶段 | 直径 | 说明 |
|---|---|---|
| 初始（0:02） | 约 1 cm | 指尖一点微光 |
| 凝聚中（0:03–0:04） | 3–5 cm | 逐渐增大，内部流光加速 |
| 完成（0:05） | 6–8 cm | 乒乓球大小，悬浮于指尖上方 2 cm |

**大小变化节奏**：先慢后快，符合「蓄势」的叙事节奏。初始 1 秒增长缓慢，随后 2 秒加速膨胀，最后 1 秒稳定。

#### 发光强度

| 参数 | 值 |
|---|---|
| 核心亮度 | 600–800 nits |
| 中层亮度 | 300–400 nits |
| 外层光晕亮度 | 50–100 nits |
| Bloom 范围 | 核心向外扩散 15–25 px |
| Bloom 强度 | 0.5–0.7（合成层） |
| 闪烁频率 | 2–3 Hz，亮度波动 ±15% |

**光照影响**：光球作为画面第二光源，在仙师面部右侧投下暖色补光，与左侧冷色环境光形成对比。附近竹叶被照亮呈青蓝色。

#### 粒子效果

| 参数 | 值 |
|---|---|
| 粒子数量 | 20–30 个（可见范围内） |
| 粒子大小 | 0.5–2 px |
| 粒子颜色 | `#c0f0ff` 青白色 |
| 运动方式 | 从指尖向外螺旋飘散，速度约 5 cm/s |
| 生命周期 | 1–2 秒，随后消散 |
| 轨迹 | 螺旋半径逐渐增大，最终脱离光球范围 |

**粒子质感**：粒子不是「火花」，而是「灵光」，运动柔和，带有轻微的闪烁。

#### 运动特征

| 参数 | 值 |
|---|---|
| 悬浮 | 光球悬浮于指尖上方 2 cm，无可见支撑 |
| 旋转 | 内部流光以 1–2 Hz 频率旋转 |
| 脉动 | 整体大小有 ±5% 的脉动，与闪烁同步 |
| 电弧 | 表面有 3–5 条电弧状细丝，长度 1–3 cm，随机跳动 |

**运动质感**：光球是「活」的，有呼吸感。它不是机械的匀速运动，而是带有生命体的微妙不规则性。

### 2.3 光屑 / 尘雾（sh010 / sh030 / sh050）

光屑与尘雾是贯穿全片的氛围特效，代表时间的流逝、灵气的弥漫、以及剑气余韵。它是「无形」的，却定义了画面的「气质」。

#### 颜色

| 场景 | 色值 | 说明 |
|---|---|---|
| sh010 氛围 | `#d4af37` 暖金 | 晨光中的浮尘，温暖而柔和 |
| sh030 爆发 | `#ffd700` + `#c0f0ff` | 金黄 + 青白混合，剑气能量与灵气交织 |
| sh050 余韵 | `#d4af37` 暖金 | 比 sh010 更稀疏，缓慢沉降 |

**色彩变化**：sh010 与 sh050 色彩一致，形成首尾呼应；sh030 为双色混合，视觉密度最高。

#### 密度

| 场景 | 密度 | 说明 |
|---|---|---|
| sh010 | 低 | 每立方米约 50–100 个可见粒子 |
| sh030 | 高 | 剑气经过处每立方米约 300–500 个可见粒子 |
| sh050 | 极低 | 每立方米约 20–50 个可见粒子，集中于剑气通道周围 |

**密度分布**：sh010 均匀分布；sh030 沿剑气轨迹呈带状分布；sh050 集中于剑气通道，呈渐疏分布。

#### 运动特征

| 场景 | 运动方式 | 速度 |
|---|---|---|
| sh010 | 缓慢上升或漂移，受体积光柱引导 | 1–3 cm/s |
| sh030 | 辐射扩散，方向与剑气方向一致 | 5–15 cm/s |
| sh050 | 缓慢沉降，速度极慢 | 0.5–1 cm/s |

**运动质感**：
- sh010：粒子在光柱中「闪烁」，仿佛被阳光唤醒的尘埃
- sh030：粒子随剑气「爆发」，带有力量感，但不过分剧烈
- sh050：粒子「飘落」，如秋叶般缓慢，暗示能量消散

#### 大小分布

| 参数 | 值 |
|---|---|
| 粒子大小 | 0.5–3 px（sh010/sh050），1–5 px（sh030） |
| 大小分布 | 正态分布，多数粒子集中在 1–2 px |
| 透明度 | 15–25%（sh010），30–50%（sh030），10–20%（sh050） |

**大小质感**：粒子不是「光点」，而是「微尘」，大小不一，边缘柔和，无清晰轮廓。

#### 与光线的互动

| 场景 | 互动方式 |
|---|---|
| sh010 | 粒子在体积光柱中可见度较高，光柱外几乎不可见 |
| sh030 | 粒子被剑气照亮，呈金黄色；远离剑气处恢复暖金色 |
| sh050 | 粒子在竹叶边缘光照射下呈微弱暖金色 |

**互动质感**：粒子是「光」的载体，而非「光」本身。它们不发光，但能反射/散射环境光，在光束中显形。
